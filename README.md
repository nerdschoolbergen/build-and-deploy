# Build and Deploy

In this workshop we'll learn about building and deploying a simple front-end application.

## [Open presentation slides](https://docs.google.com/presentation/d/154qqZcgoTQ75gjxiDckCbRjsiXVQ5XXkQV_l1WuwxYQ/edit?usp=sharing)

## Focus of this lesson

We'll look at the infrastructure of deploying an app to production and not the app itself.

## What you need

* A laptop with [Node.js](https://nodejs.org/en/download) 26 or newer, Git and [Visual Studio Code](https://code.visualstudio.com)
* A free [GitHub](https://github.com/signup) account
* A free [Cloudflare](https://dash.cloudflare.com/sign-up) account (no credit card needed)

## Prerequisites

* Some previous experience with Git and GitHub is helpful

## How to get started

* Open [Exercise 1](./exercise-1/README.md).
* Remember to ask an instructor if you're stuck.

### Symbols and notation used in exercises

#### Icons with special meaning

:pencil2: - A task you should do  
:book: - A section of text to read (no tasks, just information).  
:bulb: - Additional information.  
:exclamation: - Something important.  
:question: - Open-ended question for the reader ("What do you think would happen if...")  
:poop: - Bad practice (don't-do-this)  
:star: - A bonus task (not required)  

#### Keyboard keys

Will look like this:

<kbd>CTRL</kbd> + <kbd>ALT</kbd> + <kbd>C</kbd>

#### Diff blocks

Emphasizes how lines of text should change.

```diff
- this text was removed
+ and replaced with this text
```
